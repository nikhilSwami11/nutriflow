# Next image batch (20)

1. gemini.google.com, start a new chat, pick the image tool.
2. Paste one prompt per message, in the order below. Check the dish matches before the next one; if it is wrong, regenerate before moving on.
3. Download each image right after it is made (do not download them all at the end: download order is how they get named).
4. Run `node scripts/name-recipe-images.mjs --dry` to see which file becomes which slug, then without `--dry` to move them into `art-src/recipes/`. It reads ~/Downloads; pass a folder if you saved them elsewhere.
5. Tell Claude "added".

Skipped a prompt? Generate it last and rename that one file by hand, or tell Claude which dishes are in the batch.
