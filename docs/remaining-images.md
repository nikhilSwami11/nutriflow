# Remaining images: copy-ready prompts (110)

Every prompt below is complete: the dish name, what it looks like, then the style. Paste one per message, in order, and download each image right after it is made.

1. Dishes (sections A, B, C): gemini.google.com, a new chat, the image tool. Then `node scripts/name-recipe-images.mjs --dry` (and without `--dry`) to name the downloads in prompt order into `art-src/recipes/`, then `node scripts/prepare-recipe-images.mjs` (cuts out the white, 512px webp into `public/recipes/`).
2. Pantry items (section D): save each as `art-src/ingredients/<slug>.jpeg` by hand, then `node scripts/prepare-recipe-images.mjs ingredients` (256px into `public/ingredients/`).
3. Tell Claude "added" and which slugs, and it switches them on.
